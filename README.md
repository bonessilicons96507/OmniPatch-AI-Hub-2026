## FAQ

### What exactly does OmniPatch do?

OmniPatch is a management tool that helps you configure, update, and enable optional features in popular AI desktop applications like ChatGPT, Claude, and GitHub Copilot. It provides a single interface to manage all your AI tools efficiently.

### Is it safe to use? Will it affect my system?

Yes, OmniPatch is designed with safety in mind. It performs reversible operations, creates system restore points before making changes, and does not interact with system-critical files. All modifications are isolated to the target AI applications.

### Which operating systems are supported?

While primarily developed for Windows (Windows 10/11), OmniPatch has planned support for macOS and Linux in future versions. The current release focuses on delivering a stable and feature-rich experience for Windows desktop users.

### How do I update OmniPatch itself?

OmniPatch includes an auto-update feature that checks for new versions on startup. You can also manually check for updates from the 'About' section in the application menu. Updates are downloaded and applied seamlessly.

### Can I revert a patch if something goes wrong?

Absolutely. OmniPatch includes a comprehensive rollback feature. For every change made, it logs the action and allows you to revert to the previous state with a single click from the patch history or logs section.

### Does it require an internet connection?

An internet connection is needed for initial activation, downloading updates for AI apps, and checking for OmniPatch updates. The core patching and management functions can work offline once configured.

### Which AI applications are currently supported?

Version 1.0 supports patching and management for ChatGPT Desktop, Claude Desktop, Perplexity AI, Microsoft Copilot, Cursor IDE, GitHub Copilot, Devin, and JetBrains AI Assistant. Support for new apps is added regularly.

### Is my API key or login data secure?

OmniPatch does not store, collect, or transmit any of your personal API keys or login credentials. All sensitive data remains on your local machine and is only used by the target applications themselves.

### How do I report a bug or request a feature?

You can open an issue on the official GitHub repository page for OmniPatch. Please provide a detailed description, steps to reproduce, and your system information. Feature requests are also welcome in the Issues tab.
